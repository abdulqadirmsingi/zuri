# Zuri brand assets

Original artwork made for Zuri: a Z of two slanted-cut bars joined by a saffron diagonal, one fast stroke.

| File                                          | Use                                                                                                        |
| --------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `zuri-mark.svg`                               | The mark on a light background (ink bars, saffron diagonal)                                                |
| `zuri-mark-on-dark.svg`                       | The mark on a dark background                                                                              |
| `zuri-mark-black.svg` / `zuri-mark-white.svg` | One-colour versions for print, stamps and watermarks                                                       |
| `zuri-logo.svg` / `zuri-logo-on-dark.svg`     | Mark plus the "zuri" wordmark. The wordmark is drawn as strokes, so it needs no font                       |
| `zuri-icon.svg` / `zuri-icon-light.svg`       | App icon on a rounded square (dark / light)                                                                |
| `favicon.svg`, `favicon.ico`                  | Browser tab icon (ico holds 16, 32 and 48 px)                                                              |
| `*.png`                                       | Transparent PNG exports; icons at 16–1024 px, 180 px for Apple touch, 192 and 512 px for web app manifests |

Colours: ink `#121212`, saffron `#F99532` (the `--accent` token), white `#FFFFFF`.
Keep clear space around the mark of at least the height of one bar, and don't recolour the diagonal or straighten the cut ends.
