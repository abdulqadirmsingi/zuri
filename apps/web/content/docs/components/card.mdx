Use `Card` to group related content into one unit, such as a wallet balance or a plan. It is a container, not a control: if the whole card should be clickable, put a link inside it and stretch the link, rather than making the card a button.

<InstallTabs name="card" />

## Usage

```tsx
import { Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@/components/ui/card";

<Card>
  <CardHeader>
    <CardTitle>Wallet</CardTitle>
    <CardDescription>Available to spend</CardDescription>
  </CardHeader>
  <CardContent>TZS 240,000</CardContent>
  <CardFooter>…</CardFooter>
</Card>
```

## Accessibility

- A card is a plain `<div>` with no role, so it adds no noise for screen readers.
- `CardTitle` is a real heading. Choose its level to match the page, and never skip levels.
- The default card border is decorative; the `outline` variant uses the stronger control-border colour.

## Tokens used

`--background`, `--foreground`, `--border`, `--control-border`, `--muted-foreground`, and the glass variables.

## Known limitations

- No image slot or clickable-card pattern yet.
- Glass text contrast has not been measured against worst-case backdrops.
