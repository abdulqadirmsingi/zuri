Use `Picker` when you want a dropdown that looks and behaves the same on every device. Unlike the [Select](/docs/components/select), which uses the browser's own menu, the Picker draws its list itself, so it matches your theme, can group options, and adds a search box when the list is long.

Choose the **Select** when the native menu is what you want, for example for very short lists on phones. Choose the **Picker** for everything else.

## Installation

<InstallTabs name="picker" />

This also installs the [Popover](/docs/components/popover), which it is built on.

## Usage

```tsx
import { Picker } from "@/components/ui/picker";

<Picker
  options={[
    { value: "starter", label: "Starter" },
    { value: "team", label: "Team" },
  ]}
  defaultValue="team"
  onValueChange={(plan) => console.log(plan)}
/>
```

Give it a visible `<label htmlFor>` and an `id`, or an `aria-label`. Pass `name` to submit the value with a form.

## Search and groups

From 8 options up it adds a search box automatically. Options can have a `group` (listed under a heading) and `keywords` (extra words the search matches, such as a currency code).

## Accessibility

- The trigger is a real `<button>` with `role="combobox"`, `aria-haspopup="listbox"` and `aria-expanded`. It is named by a label, or by `aria-label`.
- The list is a `listbox` of `option`s with `aria-selected`; the highlighted option is announced through `aria-activedescendant`, so focus stays in one place.
- **Keys:** Enter, Space or the click opens it. Arrow keys move (skipping disabled options), **Home** and **End** jump to the ends, **Enter** chooses, **Esc** closes, and typing jumps to a match. With a search box, type to filter.
- Focus returns to the button when it closes. After a mouse click it returns **without** drawing a focus ring, so no stray border is left behind; after a key press the ring shows as normal.
- Targets are at least 36px tall. The panel is limited to the space available and scrolls.

## Tokens used

`--background`, `--foreground`, `--muted`, `--muted-foreground`, `--border`, `--control-border`, `--danger`, `--ring`, `--accent`, `--accent-ink` (inline variant), `--z-dropdown`, `--duration-fast`, `--ease-out`.

## Known limitations

- Single choice only. There is no multiple selection and no way to create new options.
- The whole list is rendered at once. That is fine for a few hundred options; for thousands, filter on the server and pass in the matches.
- Not tested with a real screen reader or on a real phone; only in a desktop browser and with an automated checker.
