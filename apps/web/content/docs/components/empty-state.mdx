Use `EmptyState` where a list, table or page has nothing to show yet. Say why it is empty and give one clear next step. Don't use it for errors or loading; those need their own messages.

## Installation

<InstallTabs name="empty-state" />

## Usage

```tsx
import { EmptyState } from "@/components/ui/empty-state";

<EmptyState
  title="No transactions yet"
  description="Payments you send or receive will show up here."
  action={<Button>Request a payment</Button>}
/>
```

## Props

`EmptyState` extends native `<div>` props (except `title`) and spreads them on, including `ref` (React 19).

## Accessibility

- The title is a real heading, so users can find it by heading navigation.
- The icon is decorative and hidden. Don't put essential information only in it.
- It is static content. If a list becomes empty after a user action, move focus somewhere sensible or announce the change.

## Tokens used

`--control-border`, `--muted-foreground`.

## Known limitations

- No illustrations are included; bring your own icon or SVG.
