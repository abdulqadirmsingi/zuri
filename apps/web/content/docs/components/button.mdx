Use `Button` for actions: submitting a form, opening a dialog, confirming a choice. For navigation use a link instead, because a link is announced and behaves differently.

## Usage

```tsx
import { Button } from "@/components/ui/button";

export function Example() {
  return <Button variant="outline">Continue</Button>;
}
```

## Accessibility

- It renders a native `<button>`, so Enter and Space activate it and screen readers announce it as a button.
- A visible focus ring appears on keyboard focus only (`:focus-visible`).
- Disabled buttons are removed from pointer interaction and dimmed.
- Under `prefers-reduced-motion`, the press animation and transitions are turned off.
- The smallest size is 32 pixels high, above the 24-pixel WCAG 2.2 minimum but below the 44-pixel touch target we prefer. Use `lg` for primary touch actions.

## Tokens used

`--primary`, `--primary-foreground`, `--background`, `--foreground`, `--border`, `--muted`, `--ring`, `--duration-base`, `--ease-out`, and the glass variables.

## Known limitations

- No loading state and no icon-only variant yet.
- Glass text contrast has not been measured against worst-case backdrops.
