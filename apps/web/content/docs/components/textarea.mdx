Use `Textarea` for free text over several lines, such as a message or a note. It resizes vertically only, so it can't break your layout.

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea";

<Textarea name="message" rows={5} />
```

## Accessibility

- It renders a native `<textarea>`, so Enter inserts a new line and form submission works natively.
- It needs a name: use [Field](/docs/components/field) or a `Label`.
- A visible focus ring appears on keyboard focus only.

## Tokens used

`--background`, `--foreground`, `--muted-foreground`, `--control-border`, `--danger`, `--ring`, `--duration-base`, `--ease-out`, and the glass variables.

## Known limitations

- No auto-grow and no character counter yet.
