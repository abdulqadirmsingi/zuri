Use `Reveal` to bring page sections in as people scroll to them. The demo above fades in as you scroll it into view; scroll up and reload to see it again.

Content is fully visible until the page has loaded, so it works without JavaScript and search engines see everything. Anything already on screen when the page loads is left alone, so there is no flash.

## Usage

```tsx
import { Reveal } from "@/components/ui/reveal";

<Reveal>
  <h2>Our courses</h2>
</Reveal>

{/* Stagger siblings with small delays */}
{items.map((item, i) => (
  <Reveal key={item.id} delay={i * 80}>…</Reveal>
))}
```

## Directions

`from` can be `"up"` (the default), `"fade"`, `"start"` or `"end"`. The last two slide sideways and flip in right-to-left layouts.

## Accessibility

- It is only a visual effect. The content is in the page the whole time, in reading order, and screen readers read it whether or not it has appeared.
- It does nothing under `prefers-reduced-motion`: the content just shows.
- It only moves `opacity` and `translate`, using the `--duration-slow` and `--ease-out` tokens.
- Never put the only copy of something important, such as an error message, inside a `Reveal`: it can be invisible for a moment while off screen.

## Tokens used

`--duration-slow`, `--ease-out`.

## Known limitations

- It watches the browser window, not a scrolling container inside the page.
- If the browser has no `IntersectionObserver`, the content just shows.
- Jumping past a section (the End key, an anchor link further down) shows it straight away, so nothing is left invisible behind you.
