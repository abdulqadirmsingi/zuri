title: Blocks
description: "Larger pieces for building website pages, such as heroes, a header and footer, section titles and motion."
---

Components are the small parts of an interface. **Blocks** are bigger: whole sections you place on a page. Each one installs the same way, with a single command, and you own the code afterwards.
