Use `SectionHeading` to start each section of a landing page, so headings look the same all the way down.

## Installation

<InstallTabs name="section-heading" />

## Usage

```tsx
import { SectionHeading } from "@/components/ui/section-heading";

<SectionHeading eyebrow="Courses" title="Pick a path" description="Every course ends with a project." />
```

## Accessibility

- Renders a real heading. Don't skip levels: use 2 for page sections and 3 for subsections.
- The eyebrow uses the accent *ink* colour, which meets AA contrast on white. (Plain saffron does not.)

## Tokens used

`--accent-ink`, `--muted-foreground`.

## Known limitations

- It is only the title block, not the section wrapper. You add the spacing and the section element.
