Use `ClosingCta` as the last thing before the footer, to give people one clear next step.

<InstallTabs name="closing-cta" />

## Usage

```tsx
import { ClosingCta } from "@/components/ui/closing-cta";

<ClosingCta title="Ready to start?" description="Join the next intake." actions={<a href="/apply">Apply now</a>} />
```

## Accent tone

<Preview>
  <Demo name="shell-cta-accent" />
</Preview>

On the accent fill, use a button coloured with `--accent-foreground` (dark in both themes), as here. The default primary button turns light in dark mode, so it can disappear against saffron.

## Accessibility

- A region named by its heading.
- The accent panel uses `--accent-foreground` for text, which meets AA contrast on saffron in both themes.
- The description is dimmed to 80%; keep it short, and don't put essential information only there.

## Tokens used

`--accent`, `--accent-foreground`, `--muted`, `--border`, `--foreground`.

## Known limitations

- One call to action only: it has no second panel or form layout.
