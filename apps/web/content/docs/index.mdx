Zuri is an open-source library of React components, distributed as a [shadcn](https://ui.shadcn.com)-compatible registry. You install a component with one command and the source lands in your project, so you can read it, change it and keep it.

## What you get

- **Own the code.** Components are copied into your project, not imported from a package.
- **Tokens, not hard-coded values.** Colours, radii, motion and glass surfaces come from CSS variables, with light and dark themes.
- **Accessible by default.** Native elements first, visible focus, reduced-motion support.
- **Presentation only for payments.** Payment components never store or send card, PIN or mobile-money data.

## Status

Zuri is early. Right now there is one component, [Button](/docs/components/button). The roadmap covers core primitives first, then payments and fintech UI for East Africa, forms, dashboards, AI chat and marketing blocks.
